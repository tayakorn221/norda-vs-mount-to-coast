# norda-vs-mount-to-coast

📖 อ่านออนไลน์: https://tayakorn221.github.io/norda-vs-mount-to-coast/

เทียบรองเท้าวิ่ง **Norda** (แคนาดา) กับ **Mount to Coast** (ฮ่องกง) ทั้ง 12 รุ่น เป็น HTML ไฟล์เดียว เปิดหน้าแรกจะเจอสรุปที่อ่านจบในจอเดียว รายละเอียดอยู่ด้านล่าง

## Why this exists

ข้อมูลรองเท้าวิ่งกระจายอยู่ในรีวิวภาษาอังกฤษหลายสิบเว็บ หลายแหล่งตัวเลขไม่ตรงกัน และแทบไม่มีใครพูดถึงอากาศร้อนชื้นแบบไทย หน้านี้รวบรวมไว้ที่เดียว และแยกให้เห็นว่าข้อไหนมาจากสเปกของแบรนด์ ผลวัดในแล็บ หรือความเห็นของผู้รีวิว

## Quick Start

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร (ต่อเน็ตแค่เพื่อโหลดฟอนต์)

## ไฟล์

- `index.html` คือทั้งหน้า มี CSS, JS และกราฟ SVG อยู่ในไฟล์เดียว

## ที่มา

สเปกจากเว็บของแบรนด์ ผลแล็บจาก RunRepeat (มีแค่ MtC H1, C1, M1) รีวิวจาก iRunFar, Believe in the Run, RoadTrailRun, Doctors of Running, WearTesters และเว็บอื่น ๆ ดูรายการลิงก์ครบได้ท้ายหน้าเว็บ ราคาไทยดูจากร้านที่ขายจริง ณ ต.ค. 2026

ผู้ทำไม่ได้ลองใส่รองเท้าเอง ตัวเลขทั้งหมดมาจากแหล่งข้างบน ราคาและรุ่นเปลี่ยนได้ ควรเช็กกับร้านก่อนซื้อ

## เทคนิค

- HTML ไฟล์เดียว ไม่มี build step ไม่มี library ภายนอก
- กราฟทั้งหมดวาดด้วย SVG จาก array ข้อมูลชุดเดียวในไฟล์
- รองรับโหมดสว่างและโหมดมืด (ตามเครื่อง หรือกดสลับเอง) และจอมือถือ 375px
